Troubleshooting

Start with the smallest failing workflow. Preserve the last valid Layout/route and settings; do not reinstall dependencies or reset preferences to mask an unexplained problem.

Common workflow checks

SymptomCheck in order
Generator runs, instrument does not changeGenerate mode, source Enable, Dispatch, compatible mapping, matching instance, destination lifetime; use optional binding lifecycle logging
Instrument changes, no external dataIndividual Enable/interval, explicit global Sending, transport readiness/policy, supported encoder; local simulation does not imply TX
Autopilot checkbox disabledManual movement off, valid selected route, engine/profile/gear readiness and mode. A field named Path may be the imported route's real internal name.
Weather fails while movingRead provider error, valid request coordinates and bounded movement freshness. Normal movement is allowed; large relocation invalidates geographically stale results.
Unexpected extra RX widgetInspect PGN, source address/NAME, instance and identity fields; different sources must stay distinguishable
Saved value changes at loadInspect Template Saved Value/Setup Default policies and eligible generator samples; global Sending stays off
Custom theme absentCorrect external .qss directory/extension; reopen Setup to rediscover; check readability and stylesheet validity
Old log remains after ClearChoose current channel and confirm Yes; explicit Clear/Refresh must work even with Pause selected

Controlled reproduction

  1. Stop/F12 and disconnect external hardware if it is unnecessary to reproduce.
  2. Use an isolated test profile or an intentionally disposable workspace; back up valuable files before replacement.
  3. Add the smallest relevant instrument and optional generator. Try both creation orders when a binding is involved.
  4. Compare display, Property Editor canonical value and Object Tree. Check unavailable versus genuine zero.
  5. Inspect Application Log; enable connection/disconnection detail temporarily when needed.
  6. Record expected/actual behavior and restore only the settings you intentionally changed.

For a display problem, include the selected theme, desktop scale and window size in your report. Try a built-in theme and resize the window before changing unrelated settings.
