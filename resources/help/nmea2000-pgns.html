Supported NMEA2000 PGNs

RayNmeaSimulator can receive (RX) and transmit (TX) the instrument messages listed below. In Viewer, received data creates or updates matching instruments. In Generate, enabled instruments supply outgoing values. The table describes available fields and message-specific limits.

Instrument TX requires Generate mode, individual Enable/reporting interval, a ready output and explicit Enable Sending. Local generators additionally use Enable/Dispatch. Stop/F12 revokes external Sending; it does not by itself stop local vessel movement. Actisense Release is RX-only; Debug TX is experimental. Signal K publishes only its existing mappings and has no Viewer subscription. See Signal K for the publishing limits.

RayNmeaSimulator supports 48 NMEA2000 instrument PGNs. Find each entry offline by its number or formatter.

Service and Diagnostics messages are separate

These are not additional selectable bidirectional instrument PGNs. The bounded chartplotter client receives 130064 (database list), 130065 (route list), 130066 (route attributes) and 130067 (waypoint geometry). Viewer can passively cache supported 130066/130067 records without creating instrument widgets; there is no general instrument TX encoder for these four. Authorized requests use 126208 request-group-function messages and 59904 ISO requests; responses include 126208 acknowledgements and 59392 ISO acknowledgements. This client does not implement a general route server.

Diagnostics tracks 60928 address claims, 126996 product information and 126993 heartbeats. Explicit discovery sends bounded ISO requests (59904) for NAME/product information. Other messages, including 126998 configuration information and proprietary 65311 observations, may appear only as labels or raw data. Unsupported proprietary variants remain opaque. A receiving CAN controller can still acknowledge frames and perform protocol management.

Internal IDs and unsupported traffic

Negative IDs such as -129025 (Vessel Movement), -127489 (Engine), -127493 (Transmission), -129033 (Date/Time) and -130311 (Weather), plus spacer 000000, identify local sources or layout elements. They are not transmitted PGNs. Unsupported messages can appear in Diagnostics without a matching instrument.
