Weather and Environmental Simulation

Generate Weather can use manually entered values or configured weather providers. Atmospheric, marine and descriptive observations are not interchangeable, and not every provider/station supplies every field.

Start with manual weather

  1. Add Generate Weather and compatible environmental instruments.
  2. Review source Enable and Dispatch. Leave external Sending stopped while checking bindings.
  3. Enter valid air/water temperature, humidity, pressure and wind values using the displayed units.
  4. Inspect instrument/canonical values and environmental-source status. Check which fields the provider supplies and which remain Unavailable.

Fetch provider data deliberately

  1. Review the target latitude/longitude. When Vessel Movement is connected, these can change during a run.
  2. Choose the API source. For OpenWeatherMap, configure the appropriate API key through Setup's secure storage workflow; do not paste keys into Layouts or screenshots.
  3. For National Data Buoy Center, inspect station selection/availability information. Different stations provide different atmospheric/marine subsets.
  4. Click Fetch Weather once and read the visible status. Review observation time/source rather than assuming all tabs were freshly populated.
  5. Use automatic refresh only after manual retrieval is understood, with a sensible interval and bounded provider use.

Ordinary simulated motion is allowed during retrieval. The application associates a cycle with request coordinates and applies locality/freshness safeguards; a large relocation or superseded request can legitimately invalidate a delayed result. Do not retry on every coordinate change. Current cycle locality is bounded, including a 5 km movement limit from its request snapshot; this is an application validity policy, not a provider accuracy guarantee.

Inspect the tabs and freshness

Atmosphere, Marine, More, Description and Refresh show the available conditions and scheduling controls. Check observation time, source and stale-data indications. Values restored from a Layout may be older than the current location or conditions.

When Setup enables environmental influence, valid Weather conditions contribute simulated wind drift and wave attitude. Water-current and wind-induced-yaw effects are not available. Without valid applicable conditions, those environmental effects are not applied.

Recover from provider failures

  • Check provider choice, coordinates, key availability and network/service errors before changing movement physics.
  • For missing fields, inspect station/provider coverage and observation age; choose another legitimate source rather than filling gaps with arbitrary numbers.
  • After a large position change, let the old request finish/cancel according to status, then perform a deliberate fresh retrieval.
  • Respect rate limits. Repeated retries, overlapping requests or deleting the key store are not normal recovery steps.

Fetching weather updates the Weather source. It does not enable external instrument Sending.
