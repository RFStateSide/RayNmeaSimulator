GPX/KML Import

GPX/KML Import reads one validated ordered route into pending Vessel Movement state. It does not merge unrelated routes, activate navigation or authorize transmission. Work on a copy when investigating a file from another application.

Select Route File

  1. In Generate Vessel Movement, open Autopilot and click Select Route.
  2. If offered a source choice, select Select Route File.
  3. Choose a .gpx or .kml file. The file dialog provides route folders and preserves usable sidebar navigation across repeated openings.
  4. Confirm the file. Read any validation error before changing the current simulation.
  5. Verify the route field and selection status. The internal KML name Path, for example, is a valid displayed route name, does not mean selection failed.
  6. Disable Manual movement before using Autopilot Enable; the modes are intentionally mutually exclusive.

Supported shapes and validation

FormatAccepted input / important boundaries
GPXOne route with ordered rtept points, or one continuous track segment when there is no route. GPX 1.0/1.1 and supported namespace-free files. Standalone waypoints are not an ordered route.
KMLOne LineString or supported gx:Track; supported ordered Point collections where unambiguous. Multiple paths/ambiguous separate containers are rejected rather than joined.
CoordinatesFinite latitude −90…90 and longitude −180…180 degrees. Text order in KML geometry is longitude,latitude.
Bounds4 MiB input, 25000 points, bounded XML depth/elements. Consecutive points closer than 1 mm are removed; a usable route still needs at least two distinct points.

Names, order and practical double-precision coordinates are retained. Supported KML speed metadata is interpreted in knots and converted to metres/second; absent speed metadata is not invented. An ordinary GPX route does not automatically supply a usable Route File speed profile.

Exchange one route with OpenCPN

  1. In OpenCPN's Routes manager, select one intended route and use its GPX export operation.
  2. Save to a transfer file; do not edit the live navigation database.
  3. Transfer that file and use Select Route File here.
  4. Compare route name, waypoint count/order, first/last coordinates and intermediate turns before activating simulation.

Export a single route at a time from OpenCPN. GPX file exchange does not require a chartplotter route service. Cancelled selections, malformed files and unsupported multi-route data leave the previous valid selection intact.
