Known Limitations

RayNmeaSimulator is intended for isolated simulation and inspection. It is not certified navigation equipment. These limits affect everyday operation.

AreaOperating limitation
Actisense NGT-1Release RX-only; Debug ordinary TX experimental due to unresolved outbound corruption. Active route service excluded.
Chartplotter retrievalThe target must support the required route service. Actisense active retrieval is disabled; receiving navigation data does not imply route-database access.
Signal KSupported publisher; no subscription into Viewer and no general receive-forward gateway
Bridge ModeBridge Mode is not available
Navigation outputsXTE/navigation bindings are available; APB/RMB fields are manual, without automatic Vessel Movement bindings
Message coverageGNSS reference-station/integrity fields are partial. AIS support is the listed Class B subset; unsupported radio/proprietary messages remain raw or unavailable. See the message references.
FilesSingle ordered route import; no arbitrary multi-route merge or universal proprietary metadata round trip
Raw TX captureTraffic Recording logs logical messages, not every raw outgoing CAN frame

Choose a matching installation

Use the package matching your operating system and processor. Debian 12-compatible ARM64 and native ARM64 packages have different runtime requirements. Keep supplied runtime files together. See System Requirements and Installation and First Launch.

For troubleshooting, report the interface, operation and exact status. Keep the last valid Layout and avoid resetting preferences or replacing libraries as a first step.
