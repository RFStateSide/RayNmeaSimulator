Check for Updates

Choose Help → Check for Updates... to compare your installed RayNmeaSimulator version with the latest official stable release. The window stays open alongside your workspace. Checking does not change Sending authorization, vessel movement, your route, Layout or Template.

Check and read the result

  1. Open Check for Updates. The installed version is the same application version shown in About.
  2. Wait for the latest stable version and release information. Use Check now to retry deliberately; there is no scheduled background check.
  3. If a newer compatible package is listed, choose Open official release page. Your browser opens the official RF StateSide RayNmeaSimulator release, where you can read the complete notes and choose a package.

The checker retrieves release information only. It never downloads an installer, installs software, restarts the application or requests GitHub credentials. A private project or a project without published releases reports that public release information is unavailable; this does not mean your installation is out of date.

Understand versions and packages

Versions compare numerically: 0.10.0 is newer than 0.9.0. A stable version is newer than its prerelease, such as 0.1.0-rc.1; build labels after a plus sign do not change precedence. Only stable published releases are offered. A development build compares its declared application version, not the age of its source checkout. If your version is newer than the published release, no downgrade is recommended.

A release may not have a package for your platform. Windows x64, Linux x86_64 and Linux ARM64 packages are distinct. Debian 12 ARM64 requires the Debian 12 package, not an ARM64 package built against a newer system. The checker compares published Linux runtime requirements with the running system. If it cannot verify a compatible package, read the release notes rather than substituting another architecture or upgrading system libraries.

Install an update deliberately

Download only from the official release page. Read its requirements and checksum instructions; the hash shown in the update window is published information, not independent verification of a downloaded installer. When you are ready, stop Sending and close RayNmeaSimulator yourself before upgrading. Use the Windows installer or extract the Linux package and run its supplied install.sh, following the package instructions. No developer Qt SDK should be needed for a bundled package.

Normal installer upgrades preserve user Layouts, Templates and preferences. Keep your own backup before an important upgrade. Bundled Templates are read-only snapshots; user Templates remain separate. Do not replace your system Qt or glibc to force an incompatible package to run.

If checking fails

Check your internet connection and try again later. A check stops after about 15 seconds. GitHub may temporarily limit requests or be unavailable. Invalid or incomplete release information is not used to recommend an installer. You can close the window and continue working; your current session is unaffected. Use the official project release page when available, and never enter a token or password into an update prompt.
