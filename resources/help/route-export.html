GPX/KML Export

Export Route… writes an operator-selected validated snapshot to GPX or KML. It is available for a valid selected file or complete chartplotter route. It is independent of Sending and does not activate Autopilot.

Export safely

  1. Select the intended route in Vessel Movement → Autopilot. Verify the displayed name and status.
  2. Choose Export Route… from the widget's available route actions.
  3. Select GPX or KML in the save dialog and enter a new destination filename. The matching extension is supplied where needed.
  4. If replacing an existing destination, review the explicit overwrite confirmation.
  5. Read the success/error status. Re-import the exported file into a separate/disposable session when checking interchange.

The selected source file cannot be overwritten by its own export. Symlink/canonical-path checks and destination-change checks protect the inspected destination; failed atomic replacement leaves the previous destination in place. Cancel makes no file or route-state change. A non-writable directory is an error, not permission to save elsewhere silently.

What each format carries

DataExport contract
Route/waypoint namesUTF-8 and XML escaping; duplicate names remain allowed
Waypoint orderGPX ordered rtept elements; KML ordered geometry with matching named waypoint points
CoordinatesValidated geographic bounds and practical maximum numeric precision; KML uses longitude before latitude
Service identityNMEA2000 NAME, source address, database and sparse waypoint identifiers do not become portable service identity
Absent metadataNo invented altitude, arrival radius, speed profile or proprietary extensions

Keep the original route. After importing the exported file into another application, compare waypoint order and geometry before using it.

If the save dialog looks wrong

If the save dialog is hard to use, check the folder, file type and destination permissions. Keep your preferences; report the version, platform and steps that led to the problem.
