Enable, Dispatch and Sending

Four controls answer different questions. Keeping them separate is essential when a Layout contains both dynamic sources and instruments you intend to transmit.

ControlWhat it governs
Generator EnableThe source's local operating lifecycle
Generator DispatchWhether eligible genuine samples are delivered to compatible bound instrument properties
Instrument Enable / intervalWhether this instrument is included in the authorized output schedule and how often
Enable SendingExplicit global authorization for ordinary external instrument output, subject to mode, readiness and adapter policy

Keep manual or captured values

  1. Stop external Sending while constructing the workspace.
  2. Disable unnecessary sources or turn Dispatch off before editing instrument values.
  3. Edit/restore the instrument snapshot and inspect widget, Property Editor and Object Tree.
  4. When ready for dynamic delivery, enable the source/Dispatch. Delivery resumes on a genuine eligible sample, not an invented initialization write.

With Dispatch off, generator activity does not replace your saved or manually edited values. Turning Dispatch on allows the next source update, including valid zero, to replace the corresponding value.

Start once, then stop deliberately

When the output is stopped and ready, Enable Sending is available. While Sending is active, Enable Sending is disabled and Stop is available. During connection or retry, read the status and use Stop to cancel rather than repeatedly clicking Start.

Stop Sending and F12 revoke ordinary output and pending bounded discovery/route requests. They do not promise to retract frames already accepted by an OS/adapter queue. Local simulation can continue after external output stops; disable the relevant source/movement mode when you also want local motion to stop.

Interpret disabled controls

  • Viewer disables ordinary instrument Sending.
  • No selected/ready supported output may leave Start disabled.
  • Actisense Release is RX-only; Debug TX remains experimental.
  • An enabled generator or checked instrument does not bypass these restrictions.
  • Chartplotter requests use separate bounded authorization; neither authorization silently grants the other.

Saved Enable/Dispatch states are restored configuration. Loading, startup, route selection and mode changes never automatically authorize global Sending.
