Using RayNmeaSimulator Safely

RayNmeaSimulator provides NMEA2000/NMEA0183 reception, instrument simulation and route following for controlled, isolated work. It is not a certified navigation or vessel-control system.

Prepare a session

  1. Choose Viewer to inspect incoming data or Generate to configure outgoing instrument values.
  2. Confirm source/instance identity, units and valid or unavailable fields.
  3. Start with manual values; add generators when you need changing data.
  4. Check the interface and receiving equipment before explicitly enabling Sending.
  5. Keep an independent copy of important Layouts, Templates and routes.

Loading a Layout, choosing a route, fetching weather or changing modes does not enable external Sending. Generator Enable and Dispatch control local operation and instrument updates; global Sending authorizes external output separately.

Find instructions and application details

Use Contents or Search Help to find a task or message number. Press F1 for context-sensitive Help. Select an illustration to enlarge it and use Fit or 100% to read detailed controls.

Help → About RayNmeaSimulator provides the version, publisher and license notices. Include the version, platform, connection type and status in a support request. Review shared screenshots and logs for private vessel information.

Operational judgment

Keep a known-good copy of important data, isolate tests from production navigation and stop unexpected output with Stop/F12. Already transmitted frames cannot be recalled. Follow the connected device's safety procedures; simulator output, routes and environmental effects do not constitute navigation advice or a model of all real vessel dynamics.
