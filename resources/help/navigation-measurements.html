Navigation Measurements

Use navigation fields to compare the generated course, instrument model and encoded data. They are measurements, not movement or Sending authorization. The Property Editor exposes canonical values; widgets and Object Tree apply display formatting.

Read a route-following sample

  1. With a valid pending route, disable Manual movement and explicitly enable Autopilot.
  2. Observe waypoint name, coordinates, heading/bearing, distance, XTE and time-to-waypoint in Vessel Movement.
  3. Add compatible Cross Track Error (129283) and Navigation (129284) instruments, before or after the generator.
  4. Keep generator Enable/Dispatch eligible to deliver values. Inspect canonical properties alongside the widget.
  5. At a waypoint transition or reversed endpoint, compare the new leg rather than expecting the previous leg's bearing/XTE to remain fixed.
MeasurementInterpretation
XTESigned metres canonically; displayed distance units. The existing leg calculation determines side; preserve sign when comparing local fields and encoded 129283. Zero is valid, not unavailable.
Bearing/headingCanonical radians; degrees and reference labels in the instrument. True/magnetic references must not be compared as identical.
DistanceCanonical metres; feet/miles/nautical units per preferences. Unavailable displays as Unavailable, not a huge negative distance.
ETA/timeUTC/time conventions belong to each PGN. Time-to-waypoint depends on usable speed; it is not a guarantee of arrival.

Example: −1.9288 m is approximately −6.3 ft at one decimal place. The full value remains available in Property Editor and saved Layouts. An enabled source can replace it with a newer measurement, including valid zero or Unavailable.

Autopilot updates compatible navigation instruments. APB and RMB fields can be edited manually, but automatic Vessel Movement bindings for them are not available. Review each instrument's fields before enabling Sending.
