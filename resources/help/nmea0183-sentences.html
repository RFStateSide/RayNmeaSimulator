Supported NMEA0183 Sentences

RayNmeaSimulator can receive (RX) and transmit (TX) the instrument messages listed below. In Viewer, received data creates or updates matching instruments. In Generate, enabled instruments supply outgoing values. The table describes available fields and message-specific limits.

Instrument TX requires Generate mode, individual Enable/reporting interval, a ready output and explicit Enable Sending. Local generators additionally use Enable/Dispatch. Stop/F12 revokes external Sending; it does not by itself stop local vessel movement. Actisense Release is RX-only; Debug TX is experimental. Signal K publishes only its existing mappings and has no Viewer subscription. See Signal K for the publishing limits.

RayNmeaSimulator supports 18 NMEA0183 instrument formatters. Find each entry offline by its number or formatter.

Talker IDs and sentence boundaries

The table lists formatters, not fixed talker IDs. GPRMC and GNRMC both use RMC; Viewer retains talker identity. Incoming sentences need the supported field format and a valid checksum. AIS VDM/VDO, DSC/DSE and unlisted formatters are not available as sentence instruments. NMEA2000 AIS support is separate.

NMEA0183 uses the configured serial port and baud rate. The application has no generic NMEA0183 TCP/UDP server; use an appropriate external gateway only when needed. Structured route/satellite pages must fit implemented record and sentence-length bounds; unavailable data is not silently replaced with a valid zero.
